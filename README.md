# NSR4239 – Schedule Viewer

Read-only 3-week daily / schedule viewer for the 230/115 kV Nakhon Si Thammarat Substation (GIS) project.

- Live page: https://moneykullathon.github.io/NSR4239/
- Site markup (week / month): https://moneykullathon.github.io/NSR4239/layout.html
- `index.html` is replaced on every daily update (file name must stay exactly `index.html`).
- No contract values, notes or rates are included in this file.

- [3D/4D GIS building model](https://moneykullathon.github.io/NSR4239/3d.html)
